## 📝 Project Overview

The **AI-Based Harassment Detection and Complaint Management System** is designed to provide a safe, structured, and confidential platform for reporting and managing harassment incidents.

The system combines complaint management with **AI/NLP-based harassment detection** to support efficient complaint handling, secure evidence management, and better monitoring of reported incidents.

The project focuses on important software quality attributes such as:

- Usability
- Confidentiality
- Reliability
- Integrity
- Security
- Scalability
- Responsiveness
- AI Detection Accuracy

---

## ⭐ Key Features

- 🔐 User Registration and Authentication
- 📝 Complaint Submission
- 📎 Evidence Upload and Management
- 🤖 AI-Based Harassment Detection using NLP
- 📊 Complaint Management and Tracking
- 🔔 Notification System
- 📈 Report Generation and Analytics
- 🛡️ Secure Data Storage
- 👥 Role-Based Access Control
- 🔒 Privacy and Confidentiality Protection

---

## 👤 System Roles

The system includes the following major roles:

1. **General User**
2. **Administrator**
3. **Moderator / Complaint Handler**
4. **Authority / Management**
5. **AI System**

Each role has specific responsibilities and access permissions within the system.

## 🧪 Software Testing

The project includes functional, performance, security, and AI-related testing activities.

### Functional Testing

A total of **20 functional test cases** were prepared to verify the major system requirements.

Testing covered areas such as:

- User registration and authentication
- Complaint submission
- Evidence upload
- Complaint tracking
- Notifications
- Report generation
- Administrative functions
- AI-based harassment detection
- Moderator complaint resolution

### Testing Result

Most of the functional test cases were successfully passed.

The following areas were identified as requiring further improvement:

- **FR_11:** AI-Based Harassment Detection
- **FR_19:** Moderator Resolution

These issues were documented as part of the testing process.

## 🛠️ Testing Tools and Technologies

The project uses several tools and techniques for software quality assurance and testing:

- **Selenium WebDriver** – Functional and automated testing
- **JMeter** – Performance testing
- **Postman** – API testing
- **NLP / AI Analysis** – Harassment detection testing
- **Jira / Google Sheets** – Test case and issue management

## 🔐 Security Considerations

Security and privacy are important aspects of the system.

The project considers:

- Role-Based Access Control (RBAC)
- Secure authentication
- Data confidentiality
- Encryption
- Anonymous identity protection
- Secure file upload validation
- OWASP Top 10 security considerations
- Protection of sensitive complaint information

---

## 📊 Quality Objectives

The system aims to achieve the following quality objectives:

- **Reliability:** Target availability of 99.9%
- **AI Accuracy:** Target harassment detection accuracy of 85%
- **Responsiveness:** System operations should respond within approximately 60 seconds
- **Security:** Protect user information and complaint evidence
- **Usability:** Provide an easy-to-use complaint submission and tracking process
- **Scalability:** Support increasing numbers of users and complaints
