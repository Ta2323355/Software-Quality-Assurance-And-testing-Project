## Project Title

**AI-Based Harassment Detection and Complaint Management System**


## 📌 Project Overview

This project focuses on developing an **AI-Based Harassment Detection and Complaint Management System** that provides a secure, structured, and confidential platform for reporting and managing harassment complaints.

## 🚀 Key Features

- User Registration & Authentication
- Complaint Submission & Tracking
- Anonymous Complaint Submission
- Evidence Upload
- AI-Based Harassment Detection
- Emergency / SOS Features
- Notification System
- Admin & Moderator Management
- Complaint History
- Report Generation & Analytics
- Secure Data Storage

## 🧪 Testing

The project includes:

- Functional Testing
- Unit Testing
- Integration Testing
- Acceptance Testing
- Security & Privacy Testing
- AI Output Validation
- Regression Testing

A total of **20 functional test cases** were documented and executed.

## 🛠️ Testing Tools

- Selenium WebDriver
- JMeter
- Postman
- NLP / AI-based analysis
- Jira / Google Sheets
